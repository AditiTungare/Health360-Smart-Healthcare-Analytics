# Health360 – Smart Healthcare Analytics

An interactive healthcare analytics web application developed using **Tableau, Python, and Flask** to explore patient health trends, clinical indicators, lifestyle factors, and chronic disease patterns.

## 🌐 Live Application

**Live Website:** [Health360 – Smart Healthcare Analytics](https://health360-smart-healthcare-analytics.onrender.com/)

## 📌 Project Overview

Health360 analyzes a dataset containing **5,000 patient records** to provide insights into healthcare trends and risk factors.

The project integrates interactive Tableau visualizations into a responsive Flask web application, allowing users to explore healthcare data through dashboards and analytical stories.

### Key Healthcare Insights

- **Total Patients:** 5,000
- **Heart Disease:** 30.0%
- **Diabetes:** 34.9%
- **Stroke:** 24.9%

## 🚀 Run Locally

1. Download or clone this repository.
2. Install the required dependencies:

```bash
pip install -r requirements.txt
```

3. Start the Flask application:

```bash
python app.py
```

4. Open `http://127.0.0.1:5000` in your browser.
